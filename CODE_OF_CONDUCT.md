# Project Conduct

This project exists to produce high-quality software.

Useful contributions are welcome from anyone. Code and technical discussion are evaluated on their merits. Personal characteristics are irrelevant.

Keep discussion focused on the work. Off-topic political or activist content is not welcome.

Free speech is respected, but this is not a platform for disruption or personal attacks. Persistent disruption will result in removal.

Maintainers have full discretion to enforce these standards.

If this does not suit you, other projects are available.
