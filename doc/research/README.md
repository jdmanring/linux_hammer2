# Port research, and where it came from

These documents arrived on 2026-08-29 from `Saxum`, the distribution that
consumes this port. They had accumulated there because that repository is
where the work was felt, not because they described it.

The rule that moved them: a component with its own repository owns its own
development, and the consuming repository owns only its use of that component.

## What is here

The H0 and H1 deliverables: an API map, a port plan, an upstream strategy, a
license audit, a portability audit against all three BSD ports, three readings
(spin audit, DIO design, core diff), a test fixture plan, a vendored-library
survey, an estimate, a comparison against Kusumi's ports, and
`hammer2-provenance.csv` - the per-file provenance survey of the upstream
trees, generated by `script/hammer2-provenance.py`.

Each is dated and left as written. The `proposals/` paths they cite are
Saxum's storage proposal, which is not in this tree, and the specification
pass and implementation phase they name are the two halves of the port
plan, not anything in this repository's history.

"Left as written" covers the measurements and the prose. It does not cover
a path into this repository, because the move is what changed those: the
three analysis tools came here and live at `script/` singular, while
Saxum keeps its package and `scripts/hammer2-toolchain.nix`. Five
citations were left pointing at `scripts/hammer2-*.py` after the move and
were corrected on 2026-09-27; a `scripts/hammer2-toolchain.nix` reference
is Saxum's and is correct as written. The distinction is which tree the
named file is in, so a reference that resolves nowhere is a defect and a
dated number is not.

`doc/upstream/` beside this holds the filing drafts.

## What deliberately stayed in Saxum

The split is not "everything with hammer2 in the name". That distribution
keeps the package, the six `test-hammer2` gates, their committed fixture
manifests, and the C harness one of those gates compiles. Those check what it
ships.

## primary/, captured sources

`primary/` arrived on 2026-10-10 and is different in kind: it holds other
people's documents, kept so that a claim in this repository can be
checked without a second fetch. Dillon's 2015 HAMMER2 design document,
the CCMS sources from before DragonFly deleted them in `94491fa098`, and
the twelve papers and specifications behind the comparable-systems survey
in `../CCMS_REFERENCE.md`. `primary/PROVENANCE.txt` names the URL or `git
show` and the extraction command for each file, and says which two survey
sources were deliberately not captured and why.

A question about cache coherency starts at `../CCMS_DESIGN.md` for what is
decided and open, and `../CCMS_REFERENCE.md` for where each claim comes
from. Neither should need a network fetch.

## These documents are governed

`script/test-doc-prose.sh` runs vale over `doc/`, with the config and styles
that moved here with the files. That is not decoration. In Saxum these
documents were in a structure gate and in NO prose gate for months, and twelve
British spellings were sitting in them when the corpus finally widened.
Prose moved out of a governed tree and left ungoverned reproduces that.

The gate asserts a non-empty population, because a sweep that matches nothing
must not be able to pass.

`primary/` is the one exception, excluded by path: those files are
quotations, 246 findings in the IETF's and Microsoft's text when they
arrived, and editing them to satisfy a style rule would falsify them.
